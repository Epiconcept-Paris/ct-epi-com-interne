# Conventions éditoriales — Communication interne Epiconcept

Tirées de l'analyse de 3 communications internes existantes (SAM Environnement, SAM Social, Epifun 30 ans).

## Ton général

- **Chaleureux et collectif** : « Bonjour à toutes et à tous », « on a hâte de vous retrouver », « nous comptons sur vous »
- **Factuel sans être sec** : on annonce des informations concrètes (dates, lieux, modalités) mais en gardant un registre humain
- **Reconnaissance/valorisation** quand pertinent : « Déjà plus de 30 participants : bravo et merci ! 👏 »
- **Pas de marketing-speak** : éviter les superlatifs creux (« incroyable », « extraordinaire »), préférer des formulations concrètes
- **Humour léger acceptable** : les exemples contiennent des touches d'humour (le « PS : ce message est 100% ChatGPT-free » de SAM Environnement)

## Structure type d'un mail

```
[Bandeau image haut]

[Titre principal avec emoji]
(ex. 🌍 Calculez votre empreinte Carbone !)

Bonjour à toutes et à tous,

[1-2 phrases de contexte/accroche]
(ex. « Déjà plus de 30 participants : bravo et merci ! 👏 »)

[Section principale — ce qu'il faut faire/savoir]
👉 [Call-to-action principal en évidence]

[Sections secondaires avec emoji-ancres]
🎨 SECTION
🏆 SECTION
📋 SECTION

[Date butoir / contraintes en gras]
Réponse avant le **vendredi 19 JUIN**

[Salutation de clôture courte]
À très vite,
L'équipe X

[Optionnel : PS, contact direct, mention spéciale]
```

## Emoji-ancres récurrents

| Emoji | Usage |
|---|---|
| 👋 / 🙋 | Salutation, intro |
| 👉 | Call-to-action principal |
| 🎨 | Thème, créativité, design |
| 🏆 | Concours, prix, récompense |
| 📋 | Programme, agenda, planning |
| 📅 | Date |
| 📍 | Lieu |
| ⏰ | Horaire, deadline |
| 🌍 | Environnement, planète |
| 🎉 | Événement festif |
| 🎂 / 🎊 | Anniversaire, célébration |
| 🧑‍🏫 / 👩‍🏫 | Formation, atelier |
| 💡 | Idée, conseil |
| ✨ | Mise en valeur, magie |
| ⚠️ | Attention, contrainte importante |
| 👏 | Bravo, remerciement collectif |

Ne pas surcharger : 1 emoji par ancre, 3-5 ancres max dans le corps.

## Signature

**Format observé :**

```
À très vite,
L'équipe Epifun 🎊
```

ou

```
L'équipe SAM ENVIRONNEMENT (Lore, Fabrice, Maud, Valentin & Yohann)
Vous pouvez nous écrire directement sur sam-environnement@epiconcept.fr
```

Pour un groupe de travail SAM ou similaire : nommer les membres entre parenthèses. Pour un groupe « public » (Epifun, DSI, Direction) : juste le nom de l'équipe.

## Conventions de sujet (email subject)

**Pattern :** `[emoji] [PRÉFIXE] [Titre orienté action]`

- **Emoji** en début : thématique (🌍 environnement, 🎉 événement, 🧑‍🏫 formation…)
- **Préfixe entre crochets** quand l'émetteur est un groupe identifiable : `[SAM ENVIRONNEMENT]`, `[SAM Social]`, `[DSI]`, `[Direction]`
- **Mention `RAPPEL` / `REMINDER`** en majuscules pour les relances
- **Titre court, orienté action** : verbe à l'impératif quand possible (« Calculez… », « Inscrivez-vous… », « Découvrez… »)

**Exemples bons :**
- `🌍 [SAM ENVIRONNEMENT] RAPPEL Calculez votre empreinte CARBONE !`
- `🎉 Epiconcept 30 ans – Thème soirée : Année 90 !`
- `🧑‍🏫 [SAM Social] Inscrivez-vous à l'atelier "Diversité, équité, inclusion"`

**Exemples à éviter :**
- `Information importante` (trop vague)
- `Communication interne du 15 juin` (formel et plat)
- `Re: question sur l'empreinte carbone` (préfixe email parasite)

## Bilingue FR + EN

Quand le mail s'adresse aussi aux équipes internationales (Océan Indien, partenaires anglophones) :

1. Mettre `🇬🇧 english version below` en petit juste sous le titre principal (FR)
2. Mettre la version FR en entier
3. Insérer un divider horizontal (`<hr>` ou trait CSS)
4. Mettre la version EN avec son propre titre en anglais
5. La version EN est une **adaptation**, pas une traduction littérale :
   - On garde le ton chaleureux
   - On adapte les références culturelles (ex. « Vendredi 19 JUIN » → « Friday 19 June »)
   - On garde le même nombre de sections et la même structure

## Footer standard

Tous les mails terminent par un bloc footer fixe (à part la signature) :

```
Copyright © 2026 EPICONCEPT
Vous recevez cet email en tant que salarié·e d'Epiconcept / You are receiving this email as an Epiconcept staff member.

Epiconcept · 25, rue Titon · Paris 75011 · France
```

Le footer est en petite police (11-12px), gris (`#999999`), centré.

## Mises en garde

- **Pas de "Cher·e·s collègues"** — trop formel pour la culture Epiconcept
- **Pas de "Bien cordialement"** ni "Bien à vous" — la culture est plus directe (« À très vite, », « Merci ! »)
- **Pas de "Veuillez trouver ci-joint"** — formulation administrative, à proscrire
- **Pas de bouton "Cliquez ici"** générique — toujours un texte de lien explicite (« Calculez votre empreinte », « Inscrivez-vous à l'atelier »)
- **Éviter les acronymes non expliqués** — la première occurrence d'un sigle interne doit être explicitée
